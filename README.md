# 📱 Inclusão Digital para Idosos

Projeto de um site voltado à **inclusão digital de pessoas idosas**, desenvolvido como parte de uma pesquisa sobre as principais dificuldades encontradas no uso da tecnologia.

🚧 **Status:** Em desenvolvimento — fase de pesquisa e prototipação.

A interface disponível neste repositório é apenas uma **prévia inicial do projeto**. As funcionalidades e o conteúdo ainda serão definidos a partir dos resultados da pesquisa.
